# 🧸 Labubu Empire — Telegram WebApp Тапалка (₽)

Полнофункциональная production-ready Telegram Mini App тапалка с валютой **Рубли (₽)**, интерактивной многоэтажной визуальной фабрикой, PvP дуэлями (казино), P2P переводами, защитой от накрутки и скрытой админ-панелью.

---

## 🌟 Основные возможности

1. **Главный экран кликера**:
   - 7 уровней персонажей Labubu (`1lvl.png` — `7lvl.png`) с динамической эволюцией скинов.
   - Физика интерфейсов Apple: реакция на `pointerdown` (0 мс), пружинный отклик, 3D-наклон диска.
   - Эволюция эффектов (от изумрудного кольца до радужной сверхновой на 7 уровне).
   - Всплывающий урон, 7% шанс крита («КРИТ! x5»), сбалансированный режим комбо-бонуса (+25%).
   - Отдельная плашка прогресса эволюции с точной стоимостью и шкалой накопления.
   - Отдельная кнопка прокачки кликов и запаса энергии.
2. **Визуальная Фабрика (Пассивный заработок)**:
   - 7 этажей (цехов) с переключением тапом.
   - Аппаратный **HTML5 Canvas 2D (60 FPS)**: плавное падение фигурок из 1–4 труб с физикой гравитации и мягким сжатием (squash & stretch) при приземлении.
   - Бесконечная лента и бронированный сейф, собирающий продукцию и начисляющий пассивные рубли.
   - Прокачка: скорость ленты (1..10), темп сборки (1..10), число автоматов (1..4) и разблокировка этажей.
3. **Безопасность и Античит**:
   - Серверный расчёт доступной энергии по серверным часам: `(now - lastSyncTime) * regenRate`.
   - Защита от прямого майнинга: запросы через curl/скрипты без накопленной энергии дают 0₽ прибыли.
   - Лимит частоты кликов: не более 20 тапов/сек.
   - Ограничение офлайн-дохода максимумом 3 часа.
4. **P2P Переводы**:
   - Перевод рублей любому игроку по `@username` или ID через атомарные транзакции PostgreSQL `prisma.$transaction`.
   - История входящих и исходящих операций.
5. **Казино & PvP Дуэли**:
   - Игры: **Монетка (50/50)** и **Кости**.
   - Произвольная ставка (любая сумма от 10 ₽) + быстрые кнопки и кнопка «Ва-банк».
   - Открытые комнаты других игроков и режим «Быстрый бой» с напряженной 3D-анимацией исхода.
6. **Лидерборды и Рефералы**:
   - Рейтинги по балансу, доходу фабрики и числу приглашенных друзей.
   - Индивидуальная ссылка приглашения, шеринг в Telegram, награды (+1 000 ₽ другу, +5 000 ₽ пригласителю + 10% от дохода).
7. **Скрытая Админ-панель (`/admin`)**:
   - Защита паролем администратора или скрытый вход через 5 тапов по версии в настройках.
   - Начисление и списание рублей, бан/разбан пользователей, статистика денежной массы.
8. **Web Audio API + Telegram Haptics**:
   - Процедурный синтез звуков кликов, монет, фанфар и ударов без внешних аудиофайлов.
   - Нативная вибрация Telegram `HapticFeedback`.

## 🛠️ Стек технологий

- **Фронтенд**: Next.js 14 (App Router), React 18, Tailwind CSS, Framer Motion, HTML5 Canvas, Lucide Icons, Canvas Confetti.
- **Бэкенд**: Next.js Route Handlers, Node.js.
- **База данных**: PostgreSQL (`labubu_tap`), Prisma ORM.
- **Telegram Bot**: Zero-dependency бот на нативном Node.js fetch (`bot.mjs`).

## 🚀 Быстрый старт (Разработка и Тестирование)

### 1. Переменные окружения (`.env`)
```env
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/labubu_tap"
ADMIN_SECRET="your_secure_password"
TELEGRAM_BOT_TOKEN="dev_bot_token"
TELEGRAM_BOT_USERNAME="labubu_tapalka_bot"
NEXT_PUBLIC_APP_URL="http://localhost:3000"
```

### 2. Запуск приложения
```bash
# Применение схемы базы данных
npx prisma db push

# Запуск в режиме разработки
npm run dev

# Либо запуск production-сборки
npm run build
npm start
```
Приложение будет доступно по адресу `http://localhost:3000`. В браузере включен удобный Dev-режим с переключением тестовых аккаунтов в Настройках (шестерёнка в правом верхнем углу).

## 🤖 Подключение реального Telegram Бота

### Шаг 1: Создание бота в @BotFather
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/newbot`, укажите имя и юзернейм (например, `my_labubu_tap_bot`).
3. Скопируйте полученный токен (вида `123456789:ABCdefGHI...`).

### Шаг 2: Установка публичного HTTPS-адреса
Telegram WebApp требует **HTTPS** URL. Вы можете использовать свой домен с Nginx (см. `deploy/nginx.conf`) либо бесплатный **Cloudflare Tunnel**:
```bash
# Установка Cloudflare Tunnel
curl -L --output cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
dpkg -i cloudflared.deb

# Запуск туннеля на порт 3000 (обязательно с флагом --protocol http2, если UDP/QUIC заблокирован провайдером)
npm run tunnel
# или напрямую:
cloudflared tunnel --protocol http2 --url http://localhost:3000
```

### Шаг 3: Настройка .env и запуск бота
В файле `.env` укажите:
```env
TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_ОТ_BOTFATHER"
TELEGRAM_BOT_USERNAME="my_labubu_tap_bot"
WEBAPP_URL="https://ваш-домен-или-cloudflare-url.com"
```

Запустите бота:
```bash
npm run bot
```
Бот автоматически настроит кнопку меню `🎮 Играть` и начнет принимать команды `/start`!

## 🚢 Деплой на продакшен-сервер (systemd)

Для постоянной работы сервиса 24/7 с автоперезапуском при перезагрузках сервера в папке `deploy/` подготовлены готовые скрипты:

```bash
# Автоматическая установка и запуск системных служб
sudo bash deploy/setup-production.sh
```

Команда настроит две службы:
- `labubu-web.service` — веб-приложение Next.js на порту 3000.
- `labubu-bot.service` — фоновый Telegram бот.

Управление службами:
```bash
# Проверка статуса
systemctl status labubu-web
systemctl status labubu-bot

# Перезапуск
systemctl restart labubu-web
systemctl restart labubu-bot

# Просмотр логов
journalctl -u labubu-web -f
journalctl -u labubu-bot -f
```

## 🔐 Скрытая админ-панель

- URL: `/admin` (например, `http://localhost:3000/admin` или через ваш домен).
- Альтернативный вход: в окне Настроек тапните 5 раз по номеру версии внизу.
- Пароль администратора: настраивается секретной переменной `ADMIN_SECRET` в файле `.env`.
- Функционал: просмотр всех игроков, начисление/списание рублей, бан/разбан, общая статистика валюты в игре.
